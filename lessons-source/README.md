# lessons-source/

Authoritative source for the lesson-1..lesson-9 git tags.

Each subdirectory (`NN-slug/`) holds:

- `snapshot/` — the complete file tree for that lesson (everything an
  attendee should see when checked out on `lesson-N-slug`).
- `COMMIT_MSG` — the commit message used when materializing the snapshot
  as a tag. Line 1 is `Lesson N: <title>`; the body's first non-blank
  line becomes the blurb in `lessons.json`.

## Workflow

1. Edit a snapshot or its `COMMIT_MSG`.
2. Run `./scripts/rebuild-lessons.sh` — wipes and rebuilds every tag on
   the `lessons-rebuild` branch. Workshop harness (`../workshop/`) and
   generated `lessons.json` are overlaid onto every tag.
3. Verify on a tag (`git checkout lesson-2-... && npm install && npm start`).
4. Push with `./scripts/rebuild-lessons.sh --push`.

## What is NOT here

- `workshop/` — the harness (banner, slash commands) lives at the repo
  root on `main`. The rebuild script overlays it onto every tag so
  attendees get the same navigation no matter which lesson they're on.
- `lessons.json` — generated by `scripts/generate-lessons-json.sh` from
  the `COMMIT_MSG` files in this directory.
