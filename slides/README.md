# Workshop Slides

Marp-based deck for the "Build a Simple Agent — No Frameworks" workshop.

## Run

```bash
npm install              # first time only (pulls @marp-team/marp-cli)
npm run slides           # build + open in Chrome
```

## Present

In Chrome:
- **Arrow keys / Space** — advance
- **F** — fullscreen
- **P** — presenter mode (current + next slide + timer)
- **ESC** — slide grid overview

## Edit live

```bash
npm run slides:dev       # live-reload server at http://localhost:8080
```

Edit `slides/slides.md` in any editor — Chrome auto-refreshes.

## Files

- `slides.md` — Marp source
- `theme.css` — light theme with `#76B4F0` accent
- `slides.html` — built output (regenerated by `npm run slides:build`)
